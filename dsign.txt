# Design Document: AudioShield UI/UX

**Version:** 1.0

**Based on:** "Smart Banking" Aesthetic by Arounda Agency

**Theme:** "Trust, Security, & Futurism"

## 1. Design Philosophy & Visual Language

The interface interprets the "Smart Banking" aesthetic—which prioritizes high-value asset protection—and applies it to intellectual property. The look is "Dark Mode First," utilizing deep midnight blues and vibrant neon gradients to convey a sense of active, algorithmic defense.

### 1.1 Core Aesthetic ("The Vault")

* **Backgrounds:** Deep, desaturated slate blues and "true blacks" to reduce eye strain and make data pop.
* **Surface Materials:** "Glassmorphism" for panels. High-blur, low-opacity white overlays (5-10%) with subtle 1px inner strokes to create depth without clutter.
* **Accent Glows:** Soft, diffused orbital glows behind key elements (like the "Protect" button) to guide user focus.

### 1.2 Color Palette (Extracted & Adapted)

* **Primary (The Shield):** `Electric Indigo` (#6C5CE7) – Used for primary actions and active states.
* **Secondary (The Pulse):** `Cyan Ray` (#00CEC9) – Used for "Processing" animations and data visualization.
* **Success:** `Mint Neon` (#00B894) – Indicates "Secure" status.
* **Warning/Risk:** `Salmon Pink` (#FF7675) – Indicates "Vulnerable" or "Failed" status.
* **Background:** `Void Blue` (#0F1219) – Main canvas.
* **Surface:** `Glass Panel` (Linear Gradient: White 10% -> White 2%, Blur 20px).

### 1.3 Typography

* **Headings:** *Space Grotesk* or *Satoshi* (Bold, Wide tracking). Technical, modern, readable.
* **Body:** *Inter* or *Roboto* (Regular). Optimized for dashboard data density.

---

## 2. Sitemap & Information Architecture

The app is structured like a high-frequency trading terminal, but for audio assets.

1. **The Command Center (Dashboard):** Real-time overview of catalog safety.
2. **The Forge (Upload & Protect):** The core active workflow.
3. **The Vault (Library):** Historical archive of protected files and download links.

## 3. Detailed UI Specifications & Mockups

### 3.1 Screen 1: The Command Center (Dashboard)

**Layout:** 3-Column Grid (Left Sidebar Navigation, Center Main Stage, Right Activity Feed).

* **Left Sidebar (Navigation):**
* Logo: Abstract "Shield" icon in Gradient Purple.
* Menu Items: *Overview, My Vault, Protect New, Settings*.
* Style: Frosted glass vertical strip, icons only (collapsed) or text (expanded).


* **Center Stage (Hero Widget - "Security Health"):**
* **Visual:** A large, circular data visualization (donut chart) glowing in Cyan/Purple.
* **Text:** "92% Catalog Secured."
* **Subtext:** "3 Tracks currently vulnerable. 12 Protected this week."
* **Action:** Primary CTA Button "Protect New Track" (Floating, prominent shadow).


* **Bottom Center (Recent Activity Cards):**
* Row of horizontal cards resembling banking transactions.
* *Icon:* Waveform mini-graph.
* *Title:* "Midnight_Freestyle_v3.wav"
* *Status:* Badge saying "SECURE" (Green pill shape).
* *Meta:* "Processed 2m ago • RVC Protection Active."


* **Right Column (Threat Intel):**
* "AI Landscape Monitor" widget.
* Line graph showing "Detected Cloning Attempts" (simulated data to reinforce value).
* Style: Dark card with thin neon line graph.



### 3.2 Screen 2: The Forge (Upload Flow)

**Concept:** Instead of a boring file picker, this looks like scanning a biometric ID.

* **Drop Zone:**
* Large rectangular area with a dashed animated border (pulsing slowly).
* **Center Graphic:** A 3D isometric illustration of a lock or shield.
* **Text:** "Drop Master File Here (.WAV / .FLAC)"
* **Micro-copy:** "We do not train on your data. Files deleted after 1 hour."


* **Processing State (The "Banking" Animation):**
* Once a file is dropped, the card transforms.
* **Visual:** A waveform appears in the center. A vertical "scanner" line moves L->R.
* **Text Animation:** "Analyzing Frequency..." -> "Generating Noise Mask..." -> "Injecting Poison..."
* **Progress Bar:** Slim, multi-colored gradient bar filling up.



### 3.3 Screen 3: The Success State (Download)

**Concept:** A "Certificate of Deposit" aesthetic.

* **The Card:** A sleek, high-fidelity card appears in the center of the screen.
* **Visuals:**
* Left side: Album Art placeholder (or waveform).
* Right side: Security details.


* **Data Points:**
* *Protection Type:* "Anti-RVC v2"
* *Audio Quality:* "Lossless (MOS 4.8)"
* *Adversarial Noise:* "0.02% (Inaudible)"


* **Actions:**
* **Primary Button:** "Download Protected Master" (Solid White, Black Text).
* **Secondary Button:** "View Spectrogram" (Text link).

## 4. Interaction Design (Micro-interactions)

* **Hover Effects:** Cards should "lift" (scale 1.02) and the border glow should intensify when hovered.
* **Button Press:** Buttons should have a "tactile" click feel (scale 0.98).
* **Loading:** Never use a spinning wheel. Use "Data Stream" animations—lines of code or binary numbers cascading faintly in the background to imply complex calculation.

## 5. Mobile Responsiveness (The "Pocket Bank")

* **Stacking:** On mobile, the 3-column dashboard stacks vertically.
* **Focus:** The "Protect New" button becomes a sticky floating action button (FAB) at the bottom right.
* **Gestures:** Swipe left on a track in the library to "Download" or "Delete".

## 6. Implementation Notes for Frontend

* **CSS Framework:** Tailwind CSS is recommended for handling the glassmorphism (`backdrop-blur-md`, `bg-opacity-10`) and gradients.
* **Charts:** Use *Recharts* or *Chart.js* with custom gradient fills to match the neon aesthetic.
* **Icons:** Use *Phosphor Icons* or *Heroicons* (Outline style, 1.5px stroke).
